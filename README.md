# Job Hunt Website

## Project Overview
The Job Hunt website is a full-stack web application designed to help job seekers find relevant opportunities efficiently. Built primarily with the MERN (MongoDB, Express.js, React, Node.js) stack, the platform offers an intuitive and interactive user experience for searching, applying for, and managing job listings.

This project serves as a demonstration of modern web development practices, leveraging React for a dynamic front-end experience and a robust backend powered by Node.js and Express.js, with MongoDB as the database.

## Features
- **Job Search & Filtering**: Users can search for jobs based on location, industry, and job type.
- **User Authentication**: Secure login and registration using JWT authentication.
- **Job Application Management**: Users can apply for jobs and track their application status.
- **Employer Dashboard**: Companies can post job openings and manage applicants.
- **Responsive UI**: Optimized for both desktop and mobile devices.
- **Bookmarking Jobs**: Users can save jobs to apply later.
- **Real-time Notifications**: Updates on application status and new job postings.
- **Profile Customization**: Users can create and update their professional profiles.

## Technologies Used
- **MongoDB**: NoSQL database for storing user and job data.
- **Express.js**: Backend framework for handling API requests.
- **React.js**: Frontend framework for building a responsive and dynamic UI.
- **Node.js**: Server-side runtime environment.
- **JWT Authentication**: Secure user authentication and session management.
- **Redux (Optional)**: State management for efficient data flow.
- **CSS & Styled Components**: For UI design and responsiveness.

## Setup Instructions
1. **Clone the repository:**  
   ```sh
   git clone https://github.com/yourusername/job-hunt-website.git
   ```
2. **Navigate to the project directory:**  
   ```sh
   cd job-hunt-website
   ```
3. **Install dependencies:**  
   - Backend:  
     ```sh
     cd backend
     npm install
     ```
   - Frontend:  
     ```sh
     cd frontend
     npm install
     ```
4. **Start the development server:**  
   - Backend:  
     ```sh
     npm run dev
     ```
   - Frontend:  
     ```sh
     npm start
     ```
5. **Open the application in the browser:**  
   Navigate to `http://localhost:3000` to explore the platform.

## How to Use
- **Job Seekers:** Register or log in to search, bookmark, and apply for jobs.
- **Employers:** Post job listings, manage applicants, and track job openings.
- **Navigation:** Use the menu to browse jobs, manage applications, and update profiles.
